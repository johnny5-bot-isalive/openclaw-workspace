# Local Market Coverage Map

## Purpose
Track the Seattle/Eastside/driving-range opportunity universe explicitly so the Emily search can work toward local-market exhaustiveness over time instead of drifting prematurely into nationwide search.

## Local-first rule
- Treat roles within roughly 1 hour of Duvall, Washington as the primary market.
- Prefer hybrid over fully remote when the local fit is otherwise comparable.
- Do **not** spend meaningful recurring search effort on nationwide remote roles unless the current pass documents a fresh local saturation check.
